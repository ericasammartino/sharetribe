# ON LOT

Static homepage markup for the ON LOT marketplace.

## Preview

Open `index.html` in a browser. Add images under `assets/` (see `assets/README.md`).

## Typesense search

See [docs/TYPESENSE.md](docs/TYPESENSE.md) for installing Typesense and connecting your API keys.

## Files

- `index.html` — homepage
- `search.html` — product search results (Typesense)
- `styles.css` — layout and design tokens
- `scripts/seed-typesense.js` — upload products to Typesense (admin key)
