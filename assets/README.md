# Assets

Add your image files here:

- `logo-on-lot.png` — hero illustrated logo
- `events/` — event poster thumbnails
- `creator-spotlight.jpg` — creator feature photo
- `vendors-lot.jpg` — vendors section background
- `shop/` — category images (pins, clothing, housewares, jewelry, handmade-art)

Until images are added, browsers will show broken image icons. Replace paths in `index.html` as needed.
